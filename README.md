### 🏢 Enterprise Management System

Sistema web completo para gestão empresarial e colaboração entre equipes.

**Funcionalidades:**
- Autenticação JWT e Refresh Tokens
- Gestão de organizações, membros e equipes
- CRUD completo de projetos e tarefas
- Sistema de comentários em tarefas
- Chat em tempo real utilizando Socket.IO
- Notificações em tempo real
- Upload de arquivos (PDFs e imagens)
- Dashboard administrativo com métricas e gráficos
- Documentação da API com Swagger
- Integração completa entre frontend e backend

TypeScript, NestJS, Next.js, PostgreSQL, Prisma ORM, Socket.IO, Tailwind CSS, Shadcn/UI, JWT e Swagger
