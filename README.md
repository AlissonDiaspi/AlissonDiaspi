## 🚀 Projetos em Destaque

### 🛡️ FraudShield AI

Sistema full stack de Machine Learning para detecção de transações financeiras potencialmente fraudulentas, integrando modelagem preditiva, MLOps, backend, observabilidade e interface web.

**Funcionalidades:**
- Modelo de classificação XGBoost para detecção de fraudes.
- Pipeline de treinamento, avaliação e registro de modelos.
- Versionamento e rastreamento de experimentos com MLflow.
- API REST desenvolvida com FastAPI.
- Dashboard interativo para análise de previsões.
- Persistência do histórico de transações em PostgreSQL.
- Infraestrutura Apache Kafka para processamento orientado a eventos.
- Monitoramento com Prometheus e Grafana.
- Orquestração local com Docker Compose.
- Integração contínua utilizando GitHub Actions.

**Resultados do modelo (dados de teste):**
- **ROC-AUC:** 0.9694
- **PR-AUC:** 0.8398
- **Precision:** 86.96%
- **Recall:** 81.08%
- **F1-Score:** 83.92%

**Tecnologias:**

Python, XGBoost, scikit-learn, FastAPI, Next.js, React, TypeScript, PostgreSQL, Apache Kafka, MLflow, Prometheus, Grafana, Docker e GitHub Actions.

🔗 **Repositório:**

[FraudShield AI](https://github.com/AlissonDiaspi/fraudshield-ai)

### 🤖 Currículo Express IA

Aplicação web gratuita para criação de currículos profissionais, combinando edição guiada, templates profissionais e Inteligência Artificial para auxiliar na escrita.

**Funcionalidades:**
- Editor de currículos em múltiplas etapas.
- Integração com Google Gemini para aprimoramento de textos profissionais.
- Três templates profissionais com pré-visualização.
- Geração e download de currículos em PDF e DOCX.
- Sessões anônimas com cookies HttpOnly, sem necessidade de cadastro.
- Persistência de dados e controle de utilização de IA.
- Geração de documentos com Docxtemplater e conversão para PDF com LibreOffice.
- Validação de dados, proteção de acesso e testes automatizados.
- Interface responsiva com animações.

**Tecnologias:**

Next.js 16, React 19, TypeScript, NestJS 12, PostgreSQL 17, Prisma 7, Google Gemini, Tailwind CSS 4, Docker, Vitest e LibreOffice.
